# Security Policy

## Supported Versions
Only the latest deployed version of the main branch is actively supported with security updates. 

## Reporting a Vulnerability
If you discover a security vulnerability within this project, please DO NOT open a public issue. 
Instead, please privately report it by sending an email to the repository owner.

You should receive a response within 48 hours. If the issue is confirmed, it will be patched and a security advisory will be published.
